# Resultados

Os arquivos desta pasta são gerados pela execução do código e podem incluir:

- tabelas `.dat`, `.csv` ou `.txt`;
- históricos iterativos;
- gráficos `.png`;
- resumos de validação.

Recomendações:

- mantenha apenas resultados representativos;
- informe no README principal da pasta o comando que os reproduz;
- não edite manualmente um arquivo apresentado como saída automática;
- registre parâmetros usados na geração;
- evite versionar grandes varreduras temporárias.
