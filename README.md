## 🛠️ Tecnologias utilizadas

- **Python 3.8+**
- `numpy` — operações numéricas e vetorização
- `matplotlib` — geração de gráficos e análises visuais

Instale as dependências com:

```bash
pip install numpy matplotlib
```
