# Entradas

Esta pasta deve armazenar somente arquivos de entrada necessários para reproduzir o projeto, como configurações, matrizes ou tabelas.

Os códigos atuais usam principalmente parâmetros internos ou argumentos de linha de comando. Por isso, nenhum arquivo de entrada adicional é obrigatório neste momento.

Ao adicionar dados:

- use formatos abertos, como `.csv`, `.json` ou `.txt`;
- documente colunas, unidades e convenções;
- não inclua dados pessoais ou arquivos muito grandes sem necessidade;
- evite caminhos absolutos no código.
