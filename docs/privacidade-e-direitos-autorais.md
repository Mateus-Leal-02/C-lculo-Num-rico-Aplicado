# Privacidade e direitos autorais

## Dados pessoais

Os relatórios acadêmicos podem conter:

- nome completo;
- número de matrícula;
- turma;
- assinatura;
- informações institucionais.

Antes de publicar um repositório aberto, revise cada PDF. Para um portfólio público, normalmente é suficiente manter nome, universidade e disciplina. O número de matrícula pode ser removido.

## Materiais de terceiros

Não publique sem autorização:

- livros completos;
- apostilas comerciais;
- capítulos digitalizados;
- figuras protegidas sem licença;
- códigos copiados sem atribuição.

## Alternativas adequadas

- referência bibliográfica;
- link para fonte oficial;
- resumo escrito pelo autor do repositório;
- exercício autoral inspirado no método, com novos dados;
- pequena citação dentro dos limites legais e com atribuição.

## Situação deste pacote

Os relatórios APC/PPC foram copiados a partir dos arquivos fornecidos pelo próprio autor. O livro-texto completo não foi incluído. Os exercícios e desafios em Markdown foram redigidos especificamente para este repositório.
